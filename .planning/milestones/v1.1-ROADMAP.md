# Milestone v1.1: Harder Test Cases

**Status:** SHIPPED 2026-02-05
**Phases:** 6-8
**Total Plans:** 8

## Overview

Stress-test retrieval mechanisms with realistic memory noise to resolve the v1.0 ceiling effect and validate that interference-based retrieval outperforms baselines under challenging conditions.

## Phases

### Phase 6: Test Infrastructure

**Goal**: Noise generation toolkit for stress-testing retrieval
**Depends on**: Phase 5 (v1.0 complete)
**Plans**: 2 plans

Plans:
- [x] 06-01: Core noise types and generator functions (NoiseLevel, NoiseConfig, near-miss/clutter generators)
- [x] 06-02: inject_noise function, noisy_memory fixture, and validation tests

**Details:**
- NoiseLevel enum (NONE/LOW/MEDIUM/HIGH)
- Near-miss patterns: 40% bit overlap, aged coherence
- Clutter patterns: exactly k bits, 50/30/20 relatedness distribution
- 40 validation tests in test_noise_generators.py
- Seeded torch.Generator for reproducibility

### Phase 7: Harder Behavior Tests

**Goal**: Validate core behaviors under realistic memory load
**Depends on**: Phase 6
**Plans**: 3 plans

Plans:
- [x] 07-01: Stress test infrastructure and tunneling tests (TEST-01)
- [x] 07-02: Interference retrieval stress tests (TEST-02)
- [x] 07-03: Coherence dynamics stress tests (TEST-03) and TEST_SUMMARY.md

**Details:**
- 32 stress tests (23 passed, 9 skipped with documented reasons)
- Tunneling: ~20% success at MEDIUM, 0% at HIGH noise
- Interference: linear degradation (rank 1→6→9)
- Coherence decay: 0.59 (MEDIUM), 0.77 (HIGH) over 30 ops

### Phase 8: Metrics & Validation

**Goal**: Quantify differentiation from baselines and degradation behavior
**Depends on**: Phase 7
**Plans**: 3 plans

Plans:
- [x] 08-01: Metrics infrastructure (MRR, Recall@K, statistical tests, visualization, recency baseline)
- [x] 08-02: Baseline comparison tests (METR-01, METR-02)
- [x] 08-03: Degradation curves and report generation (METR-03)

**Details:**
- MRR as primary metric
- Mann-Whitney U test for non-parametric rank comparison
- Interference vs Random: p < 0.001 (significantly better)
- Interference vs Cosine: no significant difference (both achieve MRR 1.0 at clean)
- 4-level and fine-grained (10 points) degradation curves

## Milestone Summary

**Decimal Phases:**
- None (no urgent work required)

**Key Decisions:**
- Near-miss overlap = 0.4 (differentiates from targets)
- MRR as primary metric (single correct answer)
- Mann-Whitney U test (non-parametric comparison)
- Value-based enum lookup (avoids pytest identity issues)
- Soft metrics (statistical validation, not gatekeeping)
- n_trials scales with --update-report flag

**Issues Resolved:**
- v1.0 ceiling effect: resolved through harder noise conditions
- Enum identity across pytest modules: value-based lookup
- Coherence injection timing: override after store()

**Issues Deferred:**
- Crystallization effect not observable (needs investigation)
- Surprise detection targets clutter under noise (improvement area)
- Interference vs Cosine indistinguishable at clean conditions

**Technical Debt Incurred:**
- None accumulated (code quality patterns followed)
