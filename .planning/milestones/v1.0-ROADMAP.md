# Milestone v1.0: Coherence

**Status:** SHIPPED 2026-02-04
**Phases:** 0-5
**Total Plans:** 15

## Overview

This milestone implements coherence dynamics for the quantum-inspired memory substrate. Starting from a working foundation (HRR binding, phase encoding, interference retrieval), we add the coherence field that governs quantum vs classical behavior. Coherence decay, refresh, surprise-triggered re-coherence, coherence-modulated interference, and tunneling complete the substrate dynamics described in quantum_proposal.md. Parallel tracks fix known determinism bugs and establish clear architectural boundaries between primitive substrate and agentic layer.

### Phase 2: Coherence Effects

**Goal**: Coherence modulates interference and surprise re-coheres decayed patterns

## Milestone Summary

**Key Decisions:**

- Coherence per-pattern, not per-bit (simpler; per-bit adds complexity without clear benefit)
- Decay rate 0.05 (half-life ~14 ticks) as default
- Coherence floor 0.01 (never fully decohere)
- Refresh uses diminishing returns (50% of headroom per activation)
- Surprise magnitude = normalized Hamming distance
- Stability score = min(1.0, access_count / 10.0)
- Baseline tunneling probability 0.1, creative mode multiplier 3.0
- Initial criticality 0.5, adjustment rate 0.01

**Issues Resolved:**

- Random bit transfer in coactivation is now deterministic (seeded RNG)
- Text encoding collision at small k values fixed with 64-bit hash extraction

**Issues Deferred:**

- Patterns grow unbounded until max_bits; no backpressure (v2 scope)
- N-gram encoding (currently broken) - defer fix, leave disabled

**Technical Debt Incurred:**

- 3 hypothesis validation tests skipped (near-ceiling performance prevents differentiation)
