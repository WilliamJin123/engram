"""TEST-03: Coherence dynamics tests with noisy memory.

Validates that coherence dynamics (decay, refresh, stability, surprise)
work correctly under realistic memory load.

- Decay: Patterns lose coherence over operations without access
- Refresh: Accessing patterns restores their coherence
- Surprise re-coherence: Unexpected retrievals boost coherence

All tests output metrics for Phase 8 analysis.
"""

Import from tests.stress.conftest: STRESS_NOISE_LEVELS, StressMetrics
Import from tests.conftest: NoiseLevel, noisy_memory

Implement TestCoherenceDynamics class with:

1. **test_decay_over_operations** (parametrized by noise_level):
   - Create noisy memory with single target pattern
   - Set target coherence high (0.9) initially
   - Record initial_coherence
   - Perform 30 retrieve() operations with unrelated queries (simulate time passage)
   - Record final_coherence
   - Print decay metrics: {noise_level, initial, final, decay_amount, operations}
   - Assert: final_coherence < initial_coherence (decay happened)

2. **test_access_refresh** (parametrized by noise_level):
   - Create noisy memory with single target pattern
   - Set target coherence low (0.3)
   - Let it decay further with 10 unrelated operations
   - Record pre_access_coherence
   - Query the target pattern directly (should appear in results if interference works)
   - Record post_access_coherence
   - Print refresh metrics: {noise_level, pre_access, post_access, target_found, refresh_amount}
   - If target found in results: assert post > pre (refresh happened)
   - If target NOT found: skip with LIMITATION (noise may have overwhelmed)

3. **test_stability_affects_decay** (parametrized by noise_level):
   - Create noisy memory with 2 target patterns ("stable pattern", "unstable pattern")
   - Configure stability:
     - stable: access_count_since_modification = 20 (stability_score = 1.0)
     - unstable: access_count_since_modification = 0 (stability_score = 0.0)
   - Both start at same coherence (0.8)
   - Perform 20 unrelated retrieve() operations
   - Record both final coherences
   - Print stability comparison metrics
   - NOTE: Per INTUITION.md, high stability = crystallization = FASTER decay (counter-intuitive)
   - Document actual behavior observed

4. **test_surprise_recoherence** (parametrized by noise_level):
   - Create noisy memory with 2 patterns ("expected pattern", "surprising pattern")
   - Set surprising pattern's coherence very low (0.1) - simulates "forgotten"
   - Set surprising pattern's access_count = 0 (malleable, can re-cohere)
   - Record initial_coherence of surprising pattern
   - Use retrieve_with_surprise() querying for surprising pattern content
   - Record final_coherence after surprise retrieval
   - Print surprise metrics: {noise_level, initial, final, surprise_magnitude, delta}
   - If surprise occurred (magnitude > 0.1): assert final >= initial
   - Document any limitations

5. **test_coherence_floor_under_load** (parametrized by noise_level):
   - Create noisy memory with single target
   - Set coherence to 0.05 (just above floor of 0.01)
   - Perform 100 unrelated operations (aggressive decay pressure)
   - Verify coherence >= floor (0.01)
   - Print floor test metrics
   - Assert: coherence >= floor (floor is enforced)

Use @pytest.mark.stress and @pytest.mark.parametrize for all tests.

IMPORTANT: Coherence dynamics interact with memory store operations. Each retrieve() advances tick and applies decay to ALL patterns. Account for this in test design.
