Create tests/stress/test_tunneling.py implementing TEST-01 (tunneling with noisy memory):

```python
"""TEST-01: Tunneling tests with noisy memory.

Validates that tunneling navigates through clutter to find related patterns.
Tests single-hop, multi-hop, threshold behavior, and creative mode.

All tests output metrics for Phase 8 degradation curve analysis.
"""
```

Implement TestTunnelingThroughNoise class with:

1. **test_single_hop_tunneling** (parametrized by noise_level):
   - Create noisy memory with 2 target patterns ("source pattern", "connected target")
   - Create connection between source and target via store.create_connection()
   - Set source coherence high (0.9) - CRITICAL: tunneling requires high coherence
   - Configure tunneling: baseline_probability=0.5, min_source_coherence=0.3
   - Call retrieve_with_tunneling() with creative_mode=True
   - Capture metrics: source found, target found, successful tunnels count, tunnel to target
   - Print metrics JSON
   - Assert source is in results (direct retrieval works)
   - If tunnel to target failed, use pytest.skip() with LIMITATION message (tunneling is probabilistic)

2. **test_multi_hop_tunneling** (parametrized by noise_level):
   - Create noisy memory with 3 patterns ("source", "intermediate", "final target")
   - Create connection chain: source -> intermediate -> target
   - Set coherence: source=0.9, intermediate=0.8 (both above threshold)
   - Configure tunneling with baseline_probability=0.8
   - Retrieve with tunneling from "source" query
   - Capture metrics: which patterns found, which hops tunneled
   - Document if multi-hop succeeded or not (probabilistic, document limitation)

3. **test_threshold_behavior** (parametrized by noise_level):
   - Create noisy memory with 2 connected patterns
   - Test above threshold: set coherence=0.8, min_source_coherence=0.5
   - Test below threshold: set coherence=0.3, min_source_coherence=0.5
   - Assert: high coherence CAN tunnel (probabilistic), low coherence CANNOT tunnel (deterministic)
   - Print threshold test metrics

4. **test_creative_mode_amplification** (parametrized by noise_level):
   - Create noisy memory with connected patterns
   - Set coherence at moderate level (0.4) - above threshold but not high
   - Configure tunneling with low baseline_probability=0.15
   - Compare creative_mode=True (3x = 0.45) vs creative_mode=False (0.15)
   - Run multiple trials (5 each) with different seeds
   - Capture success rates for both modes
   - Print comparison metrics
   - Assert creative mode success rate >= non-creative rate (statistical, may need tolerance)

Use @pytest.mark.stress and @pytest.mark.parametrize("noise_level", STRESS_NOISE_LEVELS) for all tests.

IMPORTANT: Tunneling is probabilistic. Use pytest.skip() with LIMITATION message for probabilistic failures, not assert. Only assert on deterministic behavior (e.g., below-threshold cannot tunnel).
