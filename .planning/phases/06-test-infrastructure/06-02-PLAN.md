  <files>tests/conftest.py</files>
  <action>
Add to `tests/conftest.py`:

**inject_noise(store, target_ids, config) -> NoiseResult**:
- Takes existing MemoryStore, list of target pattern IDs, and NoiseConfig
- Creates torch.Generator from config.seed
- For each target_id:
  - Get target pattern from store
  - Generate near-misses using generate_near_misses()
  - For each near-miss:
    - Store in MemoryStore via store.store(nm.text, metadata={"noise_type": "near_miss", "target": target_id})
    - IMPORTANT: After storing, update the stored pattern's coherence and last_access_tick
    - store.patterns[nm_id].coherence = nm.coherence (override the 1.0 default)
    - store.patterns[nm_id].last_access_tick = nm.last_access_tick
  - Record near-miss IDs in result
- Calculate total clutter count: int(len(target_ids) * config.clutter_ratio)
- Collect all target bits for relatedness calculation
- Generate clutter using generate_clutter_batch()
- For each clutter pattern:
  - Store with metadata={"noise_type": "clutter"}
  - Update coherence and last_access_tick as above
  - Record clutter IDs
- Return NoiseResult with all IDs and config

Per CONTEXT.md: Support injecting noise into existing memory (this function).

Import: torch, generate_near_misses, generate_clutter_batch from noise_generators.
