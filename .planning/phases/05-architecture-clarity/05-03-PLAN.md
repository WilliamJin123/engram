**tests/hypothesis_validation/test_interference_beats_baselines.py:**

Structure:
```python
"""Statistical validation that interference retrieval beats baselines.

HYPOTHESIS: Phase-aware interference retrieval produces better results
than bit-overlap-only methods (Jaccard, cosine).

PASS CRITERIA:
- p < 0.05 (statistically significant)
- Cohen's d > 0.3 (small-to-medium effect size)

INVALIDATION: If interference matches or loses to baselines,
the quantum advantage is not demonstrated for this task.
"""
```

Tests to implement:

1. `test_interference_beats_jaccard_on_precision()`:
   - Generate N_TRIALS (50) test scenarios with known ground truth
   - Each scenario: create 20 patterns, pick 3 as "relevant" to query
   - Run interference_retrieval and jaccard_retrieval
   - Measure precision@3 (how many relevant in top 3)
   - Compare with t-test and effect size
   - Assert p < 0.05 and d > 0.3

2. `test_interference_beats_cosine_on_precision()`:
   - Same structure but compare against cosine_retrieval

3. `test_interference_beats_random_significantly()`:
   - Floor check - must beat random by large margin
   - Assert d > 0.8 (large effect)

4. `test_interference_finds_phase_related_patterns()`:
   - Create patterns where phase alignment indicates relevance
   - Interference should find these; Jaccard cannot (no phase awareness)
   - This is the "serendipity" test

Each test should:
- Use seeded_rng fixture for reproducibility
- Use statistical_comparator fixture for analysis
- Document what failure means for hypothesis

Create tests for the 8 intelligent behaviors from INTUITION.md:

**tests/hypothesis_validation/test_intuition_behaviors.py:**

```python
"""Tests for intelligent behaviors from INTUITION.md.

Each test validates an intuitive behavior the quantum memory
should exhibit. Tests are designed to:
1. Define clear pass criteria
2. Document limitations when behavior doesn't emerge
3. Identify what substrate capability would enable missing behaviors

BEHAVIORS:
1. Generalization - repeated exposure creates shared concepts
2. Inheritance - shared attributes stored efficiently
3. Exceptions - specific instances override general patterns
4. Certainty plasticity - crystallized hard to change, malleable easy
5. Conditionals - "if X then Y" as connected nodes
6. Meta-relationships - analogies and relationship reasoning
7. Provenance - tracking where knowledge was learned
8. History - how understandings change over time
"""
```

Implement test classes:

1. `class TestGeneralization`:
   - Store "cats are furry", "dogs are furry", "rabbits are furry"
   - Query "furry" should retrieve all three
   - Compare quantum vs baseline retrieval

2. `class TestInheritance`:
   - Store "dogs have 4 legs", "cats have 4 legs", "animals have legs"
   - Query "4 legs" should activate shared concept
   - Test if coactivation creates shared bits

3. `class TestExceptions`:
   - Store "birds fly", "penguins are birds", "penguins don't fly"
   - Query "penguins fly" should retrieve exception
   - Specific should override general

4. `class TestCertaintyPlasticity`:
   - Create low-coherence (crystallized) and high-coherence (malleable) patterns
   - Attempt to modify both via surprise
   - Crystallized should resist, malleable should change
   - Uses coherence dynamics from Phase 3

5. `class TestConditionals`:
   - Store "if sunny then go outside", "weather is sunny"
   - Query "should I go outside" should connect nodes
   - Test connection-based retrieval

6. `class TestMetaRelationships`:
   - Store "cat is to kitten as dog is to puppy"
   - Query "dog to puppy relationship"
   - Test if analogy pattern emerges

7. `class TestProvenance`:
   - Store patterns with source metadata
   - Retrieve should include provenance
   - Test metadata preservation

8. `class TestHistory`:
   - Store initial belief, then contradicting belief
   - Query should show evolution
   - Test via access_count and modification tracking

For each test:
- If quantum beats baseline: assert True
- If tie: pytest.skip("LIMITATION: [behavior] not differentiated from baseline. Required capability: [what's missing]")
- If quantum loses: pytest.fail("INVALIDATION: [behavior] worse than baseline. Hypothesis weakened.")
