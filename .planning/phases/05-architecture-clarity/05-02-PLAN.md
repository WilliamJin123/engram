<task type="auto">
  <name>Task 3: Implement baseline retrieval methods</name>
  <files>tests/hypothesis_validation/baselines.py</files>
  <action>
Create baseline retrieval implementations that quantum methods must outperform:

**tests/hypothesis_validation/baselines.py:**

1. `jaccard_similarity(bits_a: Set[int], bits_b: Set[int]) -> float`:
   - Returns |intersection| / |union|
   - 0 if both empty

2. `cosine_similarity_sparse(bits_a: Set[int], bits_b: Set[int], dim: int) -> float`:
   - Treat bit sets as sparse binary vectors
   - dot(a,b) / (norm(a) * norm(b))
   - Returns overlap count / sqrt(len_a * len_b)

3. `jaccard_retrieval(query_bits: Set[int], patterns: Dict[str, SubstratePattern], top_k: int = 5) -> List[Tuple[str, float]]`:
   - Rank all patterns by Jaccard similarity to query
   - Return top_k as [(pattern_id, score), ...]

4. `cosine_retrieval(query_bits: Set[int], patterns: Dict[str, SubstratePattern], top_k: int = 5) -> List[Tuple[str, float]]`:
   - Rank all patterns by cosine similarity to query
   - Return top_k as [(pattern_id, score), ...]

5. `random_retrieval(patterns: Dict[str, SubstratePattern], top_k: int = 5, rng: random.Random = None) -> List[Tuple[str, float]]`:
   - Random baseline - picks top_k random patterns
   - Returns [(pattern_id, random_score), ...]

Include docstrings explaining these are baselines that interference retrieval must beat to validate the hypothesis.
  </action>
