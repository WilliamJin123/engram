```python
@dataclass
class SurpriseResult:
    magnitude: float  # 0-1, how surprising
    surprising_pattern_id: str | None  # Unexpected top result
    expected_pattern_id: str | None  # What we expected as top
    participant_scores: dict[str, float]  # All participants and involvement
```

2. **compute_surprise_magnitude function:**
   - Takes expected_bits (set[int]) and actual_bits (set[int])
   - Returns normalized Hamming distance: `(bits_in_A + bits_in_B - 2*overlap) / total_active`
   - Handle edge case: both empty = 0.0 surprise
   - Returns float in [0, 1]

3. **SurpriseDetector class:**
   - `__init__(self, expectation_threshold: float = 0.1)`
   - `build_expectation(query, patterns, coherence_manager)` -> tuple[set[int], dict[str, float]]
     - Returns (expected_bits, pattern_weights)
     - Expected bits = query bits + bits from patterns where (coherence * overlap_ratio) > threshold
     - Pattern weights = dict of pattern_id -> (coherence * overlap_ratio)
   - `detect(expected_bits, expected_weights, actual_top_pattern, actual_top_id, retrieval_results)` -> SurpriseResult
     - Compute magnitude via Hamming distance
     - Identify surprising_pattern_id = actual_top if different from expected_top
     - expected_pattern_id = expected_top if it was wrong
     - participant_scores from retrieval_results

IMPORTANT per CONTEXT.md:
- Surprise is emergent, not externally injected
- No threshold for surprise magnitude - continuous function
- Zero-coherence patterns CAN be resurrected through surprise

Implementation per CONTEXT.md decisions:

```python
def apply_recoherence(
    self,
    patterns: dict[str, "EvolvingPattern"],
    surprise: "SurpriseResult",
    boost_coefficient: float = 0.5,
) -> dict[str, float]:
    """Apply re-coherence based on surprise result.

    Scaling per CONTEXT.md:
    - Surprising pattern: full proportional boost
    - Wrong prediction (expected that was wrong): medium boost (0.5x)
    - Other participants: boost scaled by contribution strength (0.3x multiplier)

    Args:
        patterns: All patterns by ID.
        surprise: Detection result.
        boost_coefficient: Convert surprise magnitude to coherence boost.

    Returns:
        Dict of pattern_id -> coherence delta applied.
    """
```

Key points:
- base_boost = surprise.magnitude * boost_coefficient
- Surprising pattern gets full base_boost (capped at 1.0 - current_coherence)
- Expected pattern gets base_boost * 0.5
- Participants get base_boost * involvement * 0.3
- All boosts are additive, capped at 1.0
- Return dict of deltas for observability/testing
- Skip if magnitude < 0.001 (no meaningful surprise)
