1. Add `coherence_exponent: float = 1.0` parameter (default linear weighting)
2. For each pattern, compute `weight = coherence ** coherence_exponent`
3. Weight the pattern's contribution to the interference score by this weight
4. Normalize weights so they sum to 1.0 (proper weighted average)

Implementation approach (from RESEARCH.md):
```python
def _retrieve_interference(
    self,
    query: EvolvingPattern,
    top_k: int,
    use_evolved: bool,
    coherence_exponent: float = 1.0,

```

The coherence weighting affects how patterns contribute to the final score. Higher coherence = higher score contribution.

IMPORTANT per CONTEXT.md:
- No hard cutoffs - even very low coherence (< 0.05) contributes proportionally
- Linear weighting (exponent=1.0) is the default
- Zero-coherence patterns still participate (can be resurrected later via surprise)

id1 = store.store("cats are furry mammals")

# Decay id2
for _ in range(20):
    store.coherence_manager.advance_tick()
store.coherence_manager.apply_decay(store.patterns[id2])

# Refresh id1
store.coherence_manager.apply_refresh(store.patterns[id1], 1.0)

print(f"Fresh: {store.patterns[id1].coherence:.3f}")
print(f"Decayed: {store.patterns[id2].coherence:.3f}")

results = store.retrieve("cats furry", method="interference")
